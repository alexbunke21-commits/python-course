# Менеджер задач

Консольний застосунок українською мовою для ведення списку справ. Він зберігає завдання та їхній статус у JSON і відкриває меню після перевірки головного пароля.

## Можливості

- Головний пароль встановлюється для поточного запуску. Вхід має три спроби.
- Під час зміни пароля програма дає дві спроби підтвердження та відхиляє слабкий новий пароль.
- Завдання можна додавати, переглядати, позначати виконаними й видаляти після підтвердження.
- Зміни автоматично зберігаються у локальному `tasks.json`. Статуси показані як `[ ]` і `[x]`.
- Пункт 7 випадково пропонує одне з невиконаних завдань.
- Некоректний номер, порожній список або невідомий пункт меню обробляються повідомленням.

## Технології

- Python 3.8+
- Стандартні модулі `json`, `random`, `getpass`, `pathlib` і `tempfile`
- Git і GitHub

## Запуск

```powershell
git clone https://github.com/alexbunke21-commits/python-course.git
cd python-course
python task_manager.py
```

Задайте головний пароль і повторіть його для входу. Під час введення пароль прихований. Оберіть номер потрібної дії або `0`, щоб завершити сеанс.
